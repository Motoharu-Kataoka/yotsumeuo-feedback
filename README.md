# Yotsumeuo — feedback

Public place for feedback and feature requests for **Yotsumeuo**, a Grasshopper plug-in for Rhino 8 on Windows that shows a live, navigable Rhino view on the Grasshopper canvas.

> **Status: pre-release.** Yotsumeuo has not been published yet. This repository is being prepared ahead of the first release, and its contents will change.

## How to send feedback

- **Feature requests and general feedback** — open an issue here. Everything posted in this repository is public.
- **Bug reports** — please send them from inside Grasshopper: **Yotsumeuo ▸ Feedback / report a bug…**. That window adds the environment details needed to investigate (plug-in version, Rhino version, graphics device and similar), and sends the report privately by default.

Before you post here, please leave out anything you would not want to be public: personal information, file paths, and confidential models or screenshots.

## What is in this repository

Text only: this page and the issue tracker. The plug-in's source code is not published here, and installers are not distributed from this repository.

## About the plug-in

- Yotsumeuo does not send anything over the network by itself. The Feedback window only opens your email app or your browser when you press its button, and you decide whether to send.
